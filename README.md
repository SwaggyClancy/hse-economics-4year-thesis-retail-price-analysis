# Анализ розничных цен

Установите зависимости командой `python -m pip install -r requirements.txt`.
Из этой папки запустите `python -m jupyter lab` и откройте `analysis.ipynb`.


Вход — JSON сборщика из `data/normalized`. Суммы хранятся в копейках.
Панель строится по сети, магазину, товару и логической дате.
Все категории остаются во входных наблюдениях. Охват магазинов и категорий
в ноутбуке показывает фактически загруженные данные. Для результатов по
городам потребуется справочник магазинов с городом точки доставки и форматом,
а для проверки полноты — план сбора и статусы заданий.
Тестовые и повторно нормализованные выгрузки могут требовать отбора перед анализом.

Когда будет готово сопоставление товаров, сохраните его как `data/input/product_links.csv`
по образцу `data/input/product_links.example.csv`. Каждая пара chain и productId должна
встречаться один раз. Общий canonicalProductId связывает позиции между сетями.
Несопоставленные позиции остаются в панели.

Следующий этап методологии — спеллы с учётом пропусков и границ наблюдения,
разрезы по городам, форматам и категориям и модели из курсовой.

## Структура папок

- `analysis.ipynb` — запуск анализа по ячейкам.
- `src/price_analysis.py` — загрузка данных и расчёты.
- `src/reporting.py` — сохранение результатов.
- `data/input/normalized/` — сюда можно положить нормализованные JSON. Если папки нет, ноутбук читает выгрузки из соседнего проекта сборщика.
- `data/input/product_links.csv` — будущая таблица связей. Рядом лежит шаблон.
- `output/tables/` — таблица охвата и дневная панель в CSV.
- `output/figures/` — график числа наблюдений по дням в PNG.

Последняя ячейка сохраняет результаты и обновляет файлы при повторном запуске. Локальные выгрузки и результаты исключены из Git.
